# claude-skills

A collection of practical, ready-to-use skills for Claude. Each folder below is a self-contained skill: drop it into Claude (or point Claude at this repo) and it activates automatically when relevant.

| Skill | What it does |
|---|---|
| [career-search](https://github.com/Viniciusvcgprofssional/Career-Search) | Automates internship/job search across LinkedIn, Indeed, and other boards, filtered against your resume. (separate repo) |
| [prompt-crafter](./prompt-crafter) | Turns a vague idea into a clear, ready-to-use prompt for another Claude chat. |
| [resume-university](./resume-university) | Turns any topic into a deep, structured study guide plus a printable summary, as if you had 4 hours to master it. |
| [credit-indicator](./credit-indicator) | Estimates and shows your Claude usage/credit consumption at the end of responses. |
| [guide-automatic](./guide-automatic) | Generates a dense, encyclopedia-style reference book on any topic. |
| [reference-analysis](./reference-analysis) | Cross-checks the bibliography of an academic paper against the paper itself to flag gaps. |
| [science-practice](./science-practice) | Grounds any plan, product, or strategy in real scientific literature and frameworks. |
| [word-personalize](./word-personalize) | Builds custom Word templates, including ABNT academic formatting. |
| [luxury](./luxury) | Generates 100+ position rankings of luxury brands for any market/segment. |
| [git-to-git](./git-to-git) | Publishes/updates Claude skills to GitHub through the browser (no Git command line needed), with a mandatory personal-data and API-key scan before anything goes public. |

## Install a skill

1. Open the skill's folder.
2. 2. Download `SKILL.md` (and any `references/` files it has).
   3. 3. Add it to Claude as a skill.
     
      4. ## Why these exist
     
      5. Each skill automates something that would otherwise take real manual effort: browsing job boards, safely publishing to GitHub, building an ABNT-formatted document, cross-checking a bibliography. They're meant to be used, forked, and improved.
